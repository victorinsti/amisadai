AMISADAI — SITIO WEB

Estructura preparada para URLs sin .html en GitHub Pages.

Rutas:
/
/iglesia/
/jovenes/
/mujeres/
/cursos/
/curso1/
/kids/
/ofrendas/
/contacto/
/proxima/

Las páginas internas usan ../ para CSS, JavaScript e imágenes.
El menú móvil usa botón MENÚ/CERRAR.
Se conservaron los archivos de imágenes del proyecto.

Para probar:
1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server.
3. Para GitHub Pages, sube toda la estructura respetando las carpetas.
